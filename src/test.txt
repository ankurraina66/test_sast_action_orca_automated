## AppScan backend tools

| Tool | Purpose | Side effects |
|---|---|---|
| `get-provider-status` | Show the active provider (local or remote) | Read-only |
| `switch-provider` | Switch the backend between `local` and `remote` | Changes configuration |
| `get-apps` | List AppScan applications (optional `filter`, `top`) | Read-only |
| `get-scans` | List scans (optional `applicationId`, OData `filter`, `top`) | Read-only |
| `get-scan-issues` | Get findings for a scan (`scanId`, optional `filter`, `top`) | Read-only |
| `get-issue-details` | Get details of one finding (`issueId`) | Read-only |
| `prepare-scan` | Build a scan request for review (`appId`, `targetDir`, optional `scanName`, `scanType` of SAST or SCA, `comment`) | Does not start a scan, but returns a confirmation token |
| `execute-prepared-scan` | Start a prepared scan using its `confirmationToken` | **Starts a scan**, so it needs explicit confirmation |
| `get-scan-execution-status` | Get the status and result of an approved scan (`confirmationToken`) | Read-only, never starts a scan |
