Build Summary Generation

Background

Previously, after a successful SAST/SCA scan, the GitHub Action only printed scan results to the workflow logs. Users had to navigate to the AppScan portal to view scan information, vulnerability counts, and other scan metadata.

To improve visibility within GitHub Actions, Build Summary generation was introduced using GitHub Job Summary (GITHUB_STEP_SUMMARY).

Files Modified:

resultProcessor.js

asoc.js

Technical Implementation

The implementation uses resultProcessor.processScanResults() as the entry point after scan completion.

Once the analysis completes successfully, the workflow retrieves the scan results, aggregates vulnerability statistics, generates the markdown summary, and finally publishes it to GitHub.

Impact

Eliminates dependency on workflow logs.

Standardized markdown generation through a reusable helper.

Reused for both Build and Pull Request summaries.
