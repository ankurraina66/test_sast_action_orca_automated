Using the "appscan-connector" MCP, perform a read-only security review:

1. Call "get-scans" and list up to 5 existing scans with their names, IDs, and statuses.
2. Select one existing scan from the results and call "get-scan-issues" for that scan with "top: 5".
3. If findings are returned, call "get-issue-details" for one finding.
4. Summarize the finding title, severity, status, location, and any description or remediation information actually returned by AppScan.

Do not create scans, update issues, modify code, or invent missing information. If a tool call fails, report the actual error. Clearly mark fields that are unavailable.
