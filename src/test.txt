HCL AppScan Security Review

I can help you with the following AppScan tasks:

- Find applications and scans: Look up an application by name and list its scans, with scan type, status, and creation date.
- Investigate findings: Retrieve the issues for a scan and the details of a specific finding, including any description, evidence, trace, and remediation guidance AppScan returns.
- Correlate with your code: Locate the file and line a finding references in this workspace and read the surrounding code. I'll explain the vulnerability and its likely impact.
- Propose a fix: Suggest a minimal remediation for your review. I won't edit any source files until you explicitly approve.
- Verify changes: After an approved edit, run the available tests or checks and report what actually ran.
- Create a new scan (only on explicit request): Prepare a SAST or SCA scan, show you the exact application ID, source directory, scan type, and scan name, and run it only after you confirm.

Routine reviews are read-only and never create scans or change AppScan issues.

What would you like to review? For example, give me an application name to list its scans, or a scan and finding to investigate.
