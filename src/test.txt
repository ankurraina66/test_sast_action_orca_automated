Mixed risk

- reports (local only):
  - Operations are list, create and download.
  - Report types are Security, Issues, Regulation, License and SBOM.
  - File types are PDF, HTML, XML, CSV and SARIF.
  - SBOM formats are SPDX JSON and CycloneDX JSON.

create-scan options

- SAST: has auto, source-code-only and build-output modes. It does not run a project build.
- SCA: can optionally run npm run build first, with approval.
- DAST:
  - Needs a scanUrl.
  - Supports public or private networks (private uses a Presence ID).
  - Login can be none, credentials or a recorded sequence.
  - Optimization is fast, normal or thorough.
- Other: scan level, secret scanning, third-party code, personal scan, wait or timeout, and artifact retention.
