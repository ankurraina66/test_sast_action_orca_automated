create-scan is not available. The connector exposes eight AppScan tools, and none of them is named create-scan or create-app. I found this by searching the connector's tool list only. I did not call, prepare or execute any scan, switch providers, change files or touch credentials.

The connector exposes these tools (the same eight as in my earlier check):
- get-provider-status
- switch-provider
- get-apps
- get-scans
- get-scan-issues
- get-issue-details
- prepare-scan
- execute-prepared-scan

Scan creation is a two-step flow, which is what we used for "Spring Boot REST Service - POC SAST Validation":

┌──────┬───────────────────────┬─────────────────────────────────────────┬────────────────────────────────────────────────────────────────────────────┐
│ Step │         Tool          │                Required                 │                                  Optional                                  │
├──────┼───────────────────────┼─────────────────────────────────────────┼────────────────────────────────────────────────────────────────────────────┤
│ 1    │ prepare-scan          │ appId (UUID), targetDir (non-empty      │ scanType (SAST or SCA, default SAST), scanName (non-empty string), comment │
│      │                       │ string)                                 │  (string)                                                                  │
├──────┼───────────────────────┼─────────────────────────────────────────┼────────────────────────────────────────────────────────────────────────────┤
│ 2    │ execute-prepared-scan │ confirmationToken (UUID from step 1)    │ None                                                                       │
└──────┴───────────────────────┴─────────────────────────────────────────┴────────────────────────────────────────────────────────────────────────────┘

prepare-scan only returns a confirmation token and the parameters for review. It does not start a scan. execute-prepared-scan starts it, and only after you explicitly confirm.

The local provider reported 15 backend tools when we switched to it, and the connector exposes only the eight above. I can't see the other backend tools, so I can't say whether the backend has its own create-scan internally. The connector doesn't expose it either way.
