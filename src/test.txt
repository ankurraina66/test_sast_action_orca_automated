Steps for the plugin itself (later test)

These are standard IntelliJ and Gradle steps. They are not taken from this project's documentation.

1. In IntelliJ IDEA (build 222 or newer): Settings → Plugins → ⚙ → Install Plugin from Disk → select build\distributions\intellij-plugin-2.13.1.zip → restart.
2. Sign in under Settings → Tools → AppScan → ASoC/AppScan 360° → Login. Use your own credentials and don't paste them anywhere.
3. Open the AppScan tool window at the bottom of the IDE.
4. Alternatively, run gradlew runIde from the project directory. This opens a sandbox IDE with the plugin loaded. I haven't confirmed that the Gradle
   build works. The build file points at internal Nexus reposiain HTTP, so it may fail outside the HCL network.

None of this runs create-scan.
