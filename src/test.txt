What AppScan MCP tools are available?

The AppScan MCP server (appscan-mcp) has 12 tools. All of them use OData v4 query options ($filter, $select, $expand, $orderby, $top, $skip, $apply, $count) except get_issue_details and get_edm_metadata.

Notes

- Scope values: Application, Scan or ScanExecution. The schema also lists Applications.
- Policy modes: applyPolicies takes None, All or Select. All oen. Select also needs selectPolicyIds.
- Status values for update_issues: Open, InProgress, Reopened, Noise, Passed, Fixed, New.
- Caution with update_issues: it changes issue state in AppSca. I'd first run the same filter through get_issues with$count=true to see how many issues it hits, and I'll confirm with you before running any update.
- Large queries: an organization-wide get_issues call can retu, $top, $select or $apply to keep it small.
- Field names: call get_edm_metadata first if you're unsure which fields exist.
